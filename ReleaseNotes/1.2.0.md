FreeArc 1.2.0 是第一个公开版本：一款 macOS 上的压缩包浏览 / 解压 / 创建工具，免费、开源、无内购。

解压和压缩是系统级的基础能力，不该被拆成付费档位，也不该为了用一个右键菜单去登录、激活、联网校验。这个版本把该有的能力一次放齐，不留功能墙。

本版能力

- 浏览：图标 / 列表 / 分栏三种视图，切换后保持当前目录；嵌套压缩包可逐层进入并逐层返回；⌘ 与 ⇧ 多选、面包屑跳转、隐藏项一键显隐
- 预览：空格 Quick Look 直接渲染文档、表格、演示、PDF、图片与视频；悬停出缩略图卡片（视频可静音自动播放）；双击条目进入同一套预览窗口
- 解压：全部 / 解压所选 / 拖到访达；目录自动展开并剥离公共前缀，选了什么就得到什么；目标路径先做可写性与目录创建预检；拒绝 ../ 穿越、绝对路径与符号链接逃逸
- 创建：五种用途预设（通用分享 / Windows 用户 / Mac 间传递 / Linux 与服务器 / 尽可能小），ZIP、7Z、TAR 三种格式，压缩强度五档，分卷 64 KB – 50 GB 自定义；创建前扫描 Windows 不兼容文件名并批量修正
- 加密：ZIP AES-256 与 7Z 头加密；密码本只存本机（0600 权限），解锁成功后才询问是否保存，不静默收集
- 磁盘映像：DMG 只读挂载到访达不可见的临时挂载点，卸载无残留；标准 ISO 免挂载直读；DMG 里的一键安装会先做同名冲突预检
- 文件盒：常驻托盘的拖放暂存区，叠加态翻页与逐个网格两种显示，右键八项动作全部真实生效，闲置自动收起，八种外观
- 访达集成：右键压缩 / 解压 / 用 FreeArc 浏览；创建与解压加密包时可直接从密码本取密码，选完即执行

本版重点

搜索与定位
- ⌘F 不只是过滤当前目录：整个压缩包一次性拍平成结果列表，嵌套多少层都能搜到
- 每条结果显示名称、所在位置（完整内部路径）与大小，点瞄准镜按钮直接跳到该文件所在目录并选中
- 结果按匹配质量排序：名称完全匹配 > 名称前缀 > 名称包含 > 路径包含，目录排在文件之前

包内编辑
- ZIP 家族（zip / zipx / jar / apk）可以直接改名、删除、拖入新文件，⌘Z 撤销、⇧⌘Z 重做，保存时统一落盘
- 加密包、分卷包与 7Z / TAR / RAR / 磁盘映像保持只读，右键菜单会说明原因——宁可只读，也不做出「编辑完保存失败」或改写容器格式这种事
- 拖入同名文件三选一：替换 / 同时保留 / 取消，可对整批同名项套用同一选择；新增与替换项带绿色标记
- 保存分三段反馈（解出原有条目 → 重新打包 → 写入原文件）；JAR / APK 内含签名文件时，保存前提示签名将失效

自动更新
- 从 GitHub Releases 读取最新版本，按语义化版本比较；有新版就弹出更新介绍，可下载安装并自动重启
- 启动 10 秒后静默检查，24 小时内最多一次（用 ETag 省 API 配额）；可在 设置 → 通用 → 更新 里关闭，也可随时手动检查
- 可以「跳过此版本」，之后不再为这个版本打扰；安装失败按阶段给出具体原因

系统要求

- macOS 15 或更新
- 通用二进制，Apple 芯片与 Intel 都原生运行
- 无需另装命令行压缩工具：包内已带 7-Zip 25.01 内核（7zz）

已知限制

- RAR 只能解压，不能压缩（算法有专利授权限制），需要高压缩比时请用 7Z
- 包内编辑只支持 ZIP 家族，加密包与分卷包只读
- 自动更新走 GitHub，网络不稳定的环境可能需要代理

安装

1. 下载 FreeArc-1.2.0.zip 并解压
2. 把 FreeArc.app 拖进「应用程序」
3. 首次打开若被 Gatekeeper 拦下，到 系统设置 → 隐私与安全性 中点「仍要打开」
4. 访达右键菜单需要授权：设置 → 通用 → 访达扩展，勾选 FreeArcFinderSync
