FreeArc 1.2.1 是一次小版本更新，两处改进，均来自第一个公开版本发布后的反馈。

界面
- 应用菜单「关于 FreeArc」改为直接进入 设置 → 关于 页：版本信息、开源许可、项目链接都在那里，不再弹出系统默认的简易关于窗口
- 设置窗口已打开时，菜单直达会自动切到对应分区，不用先关窗再重开

更新检查
- GitHub 对未登录接口按出口 IP 限流（每小时 60 次，共享网络/代理出口容易被用光）；触发限流时更新检查自动改走发布页回退通道，检查不再报错中断
- 限流仍导致检查失败时，错误提示会写明原因和解决办法，不再是干巴巴的「HTTP 403」

系统要求不变：macOS 15 或更新，Apple 芯片与 Intel 通用二进制。安装方式与上个版本一致：下载 zip → 解压 → 把 FreeArc.app 拖进「应用程序」（从 1.2.0 升级也可以直接用应用内「检查更新」一键完成）。

许可与源码

GPL-3.0。源码与问题反馈都在 https://github.com/btwise/FreeArc，不满意就 fork，缺什么就补什么。
